acsh 2.0.0 is a rewrite: a POSIX shell that runs the same scripts as
BusyBox `ash`, with the same output, and is also a comfortable
interactive shell. Every claim below is backed by a test or a
measurement in the [README](https://github.com/aarushchaudhary/acsh#readme).

## Download

All binaries are statically linked with musl: one file, no libraries,
runs on any Linux of its architecture (Alpine, Debian, Ubuntu, Fedora,
BusyBox systems, `FROM scratch` containers).

| File | For |
|---|---|
| `acsh-x86_64` | 64-bit PCs and servers |
| `acsh-aarch64` | 64-bit ARM Linux (ARM servers, a Raspberry Pi with a 64-bit OS) |
| `acsh-*-minimal` | the same without the line editor, completion and suggestions: the smallest build |
| `.acshrc` | a starting `~/.acshrc` |
| `SHA256SUMS` | checksums of all of the above |

```sh
sha256sum -c SHA256SUMS --ignore-missing
chmod +x acsh-x86_64 && ./acsh-x86_64
cp .acshrc ~/.acshrc     # optional
```

## What's new since 1.0.0

**The language: `ash` parity.** A new lexer, recursive-descent parser and
executor. 50 differential test scripts give byte-identical output and
exit status under acsh and BusyBox `ash`, and real scripts run the same:
`/etc/profile`, every OpenRC init script, abuild, autoconf `./configure`.
Section-by-section POSIX.1-2024 status:
[docs/posix_compliance.md](https://github.com/aarushchaudhary/acsh/blob/main/docs/posix_compliance.md).

**Interactive shell.**
- A line editor: emacs keys, word moves, Ctrl-R history search, wide
  lines that scroll; fish-style history suggestions with `set -o suggest`.
- Tab completion of commands, files, `cd` directories, `$VAR` names and
  `apk` subcommands.
- History that keeps multi-line commands whole, honours `HISTCONTROL`
  and `HISTIGNORE`, survives parallel shells, with `fc` and
  `history -a -n -c -d -r -w`.
- Prompts with bash's escapes, `\?` and the git branch (`\g`); `PS1` is
  never exported, so other shells never see it.
- Every interactive shell, also under `su` and `docker exec`, reads
  `/etc/acshrc`, `~/.acshrc` and `$ENV`.

**Robustness.** 24 CPU-hours of fuzzing found no crash. Deep nesting,
1 MB values, arithmetic overflow and known `ash` crash inputs
(CVE-2022-48174 among them) end in a clean error. No fixed limits on
functions, aliases, jobs or name lengths.

**Clear errors.** Errors name the file and line; syntax errors show the
correct form; bash-only syntax (arrays, `declare`, `select`...) gets a
message naming the feature and the POSIX way to do it.

**Bash extras.** `<<<` here-strings, brace expansion and `printf %q`,
each checked against bash.

**Size and speed.** The minimal build starts as fast as `ash`; the full
build is within 1.13× of an `ash`-only BusyBox's size. The minimal build
is still 9% bigger and uses 8 KB more memory than `ash`: see "What ash
still does better" in the README.

## Changed from 1.0.0

- The release binaries are now static musl builds for x86_64 and
  aarch64 (1.0.0 shipped one dynamically linked glibc binary).
- `.ashrc` is no longer shipped; acsh reads `~/.acshrc`.
- Version 2.0.0 is shown by `\v` in `PS1`.
